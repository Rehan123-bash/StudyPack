# Milestone 2 reel script (about 100 seconds)

Screen recording of the browser with a voice-over. Real runs only. Must be 90–150 seconds.

## Tabs to open before recording

1. https://studypack-tokentitans.streamlit.app/
2. https://github.com/Rehan123-bash/StudyPack/blob/main/prompts/v1/P0_single_prompt.txt

Demo input: OS_Deadlocks_notes.pdf (uploaded in the app's "Upload a file" tab).

| 0:55–1:02 | The 4 numbers | "It wrote [number] verified questions." |
| 1:02–1:15 | Practice questions → Show answer under Q1 | "Each answer shows the exact line from my notes and confirms it passed the check." |
| 1:15–1:25 | Summary & key terms | "And here's the summary and key terms, linked to the notes." |
| 1:25–1:40 | Tab 5, test table | "We tested 14 inputs, including messy OCR text, Hinglish notes and a prompt-injection attack. 13 passed. Next: scanned PDFs and tracking weak topics." |
