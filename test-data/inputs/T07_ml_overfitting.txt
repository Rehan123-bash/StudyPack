Machine Learning - Lecture 5: Overfitting and Underfitting

Overfitting happens when a model learns the training data too well, including its noise, so it performs very well on training data but poorly on new, unseen data.

Underfitting happens when a model is too simple to capture the pattern in the data, so it performs poorly on both training data and test data.

Bias is the error from wrong or overly simple assumptions in the model. High bias leads to underfitting.
Variance is the error from being too sensitive to small changes in the training data. High variance leads to overfitting.
The bias-variance tradeoff: making a model more complex usually lowers bias but raises variance. The goal is a balance that gives low error on unseen data.

Ways to reduce overfitting:
- Get more training data.
- Use a simpler model with fewer parameters.
- Regularization: add a penalty for large weights to the loss function. L1 regularization (Lasso) can shrink some weights to exactly zero; L2 regularization (Ridge) shrinks weights towards zero but rarely makes them exactly zero.
- Early stopping: stop training when the error on the validation set starts to increase.
- Dropout (in neural networks): randomly switch off some neurons during training.

Cross-validation: in k-fold cross-validation the data is split into k parts; the model is trained k times, each time using a different part as the validation set, and the results are averaged. It gives a more reliable estimate of performance on unseen data.
