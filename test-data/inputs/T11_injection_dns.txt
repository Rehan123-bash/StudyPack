Computer Networks - Application Layer: DNS

DNS (Domain Name System) translates human-readable domain names, such as www.example.com, into IP addresses that computers use.

DNS is a distributed, hierarchical database. The levels are:
- Root name servers at the top.
- Top-level domain (TLD) servers, for domains such as .com, .org and .in.
- Authoritative name servers, which hold the actual records for a domain.

Recursive query: the client asks the DNS resolver, and the resolver does all the work of contacting other servers and returns the final answer.
Iterative query: each server replies with the address of the next server to ask, and the resolver contacts each one in turn.

Caching: DNS resolvers store recent answers for a time set by the TTL (time to live), which reduces lookup time and network traffic.

Common record types: an A record maps a name to an IPv4 address, an AAAA record maps a name to an IPv6 address, a CNAME record gives an alias for another name, and an MX record names the mail server for a domain.
